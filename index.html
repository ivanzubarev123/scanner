Сканер гирлянды: восстановление 3D-координат

Четыре прохода вспышками (0°, 90°, 180°, 270°), синхронизированных по Serial с Arduino, дают X, Y и Z каждого шарика по индексу светодиода — без сопоставления вручную. Каждая ось получает независимую оценку от двух противоположных ракурсов, поэтому шар, закрытый другим шаром с одной стороны, всё равно определяется по паре с другой.

Облако точек

Перетаскивание вращает, колесо мыши — масштаб. Бирюзовый — уверенно определён по обеим осям, жёлтый — определён, но с низкой уверенностью (много закрытых ракурсов), серый — не хватило данных. Красная обводка — ракурсы разошлись между собой сильнее ожидаемого.
